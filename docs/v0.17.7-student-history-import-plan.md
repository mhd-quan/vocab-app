# v0.17.7 Student History Import Plan

## Goal

Make exported student history portable across machines before adding cloud sync. A tutor should be able to take the `.json` bundle exported from one Vocab App install and import it into another install from the Students workspace, even when the target machine has no existing evidence logs or matching profile.

## Contract

- Keep the existing export envelope: `vocab.report-bundle.v1`.
- Keep the importable payload: `vocab.student-data.v1`.
- Support both plaintext `.vocab-report-bundle.json` and encrypted `.vocab-report-bundle.enc.json`.
- Treat the exported `sourceFingerprint` as the stable identity for repeated imports from the same source student.
- Resolve curriculum-linked progress by content refs instead of source database ids.

## Merge Semantics

- Student profile: create on first import, then update the mapped local profile on later imports.
- Sessions: insert first import, update matching source sessions on repeat imports.
- Learning and evidence events: deduplicate by import source markers.
- FSRS/progress rows: upsert by local student and local content item.
- Achievements and assignments: upsert without removing unrelated local data.
- Dictionary searches/reviews: deduplicate by stable local keys; dictionary learning items upsert by dictionary key.

## v0.17.7 UI Surface

- Add a top-level **Import history** action on the Students page.
- Use one shared import modal for Students and Student Detail.
- Keep export on Student Detail, but rename the action to **Export history** to match the import vocabulary.
- Show import results with session, answer, evidence, progress, achievement, and dictionary counts.
- Invalidate student, progress, evidence, rewards, and dictionary learning caches after successful import.

## Google Drive Readiness

The future sync layer should not invent a new data format. It should download or watch the same report bundle files, then call the same parser/importer path used by the manual import dialog. A later implementation can add:

- A local sync manifest keyed by `sourceFingerprint` and bundle hash.
- A Google Drive adapter that lists candidate bundle files in an app folder.
- A background import queue that runs only when connectivity is available.
- Conflict reporting that reuses the import stats shape already surfaced in v0.17.7.
